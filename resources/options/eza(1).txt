eza [options] [files...]

-1, --oneline                   Display one entry per line.
-@, --extended                  List each file’s extended attributes and sizes.

-a, --all                       Show hidden and “dot” files. Use this twice to also show the ‘.’ and ‘..’ directories.
-A, --almost-all                Equivalent to –all; included for compatibility with ls -A.
    --absolute=WHEN             Display entries with their absolute path.
-b, --binary                    List file sizes with binary prefixes.
-B, --bytes                     List file sizes in bytes, without any prefixes.
    --changed                   Use the changed timestamp field.
    --colo[u]r-scale            highlight levels of field distinctly. Use comma(,) separated list of all, age, size
    --colo[u]r-scale-mode=MODE  Use gradient or fixed colors in --color-scale.
    --colo[u]r=WHEN             When to use terminal colours (using ANSI escape code to colorize the output).
-d, --treat-dirs-as-files       This flag, inherited from ls, changes how eza handles directory arguments.
-D, --only-dirs                 List only directories, not files.
-F, --classify=WHEN             Display file kind indicators next to file names.
-f, --only-files                List only files, not directories.
    --follow-symlinks           Drill down into symbolic links that point to directories.
-G, --grid                      Display entries as a grid (default).
-g, --group                     List each file’s group.
    --git-ignore                Do not list files that are ignored by Git.
    --git                       List each file’s Git status, if tracked. This adds a two-character column indicating the staged and unstaged statuses respectively.
    --git-repos                 List each directory’s Git status, if tracked. Symbols shown are |= clean, += dirty, and ~= for unknown.
    --git-repos-no-status       List if a directory is a Git repository, but not its status. All Git repository directories will be shown as (themed) - without status indicated.
    --group-directories-first   List directories before other files.
    --group-directories-last    List directories after other files.
-h, --header                    Add a header row to each column.
-H, --links                     List each file’s number of hard links.
    --hyperlink                 Display entries as hyperlinks
-I, --ignore-glob=GLOBS         Glob patterns, pipe-separated, of files to ignore.
-i, --inode                     List each file’s inode number.
    --icons=WHEN                Display icons next to file names.
-l, --long                      Display extended file metadata as a table.
-L, --level=DEPTH               Limit the depth of recursion.
-m, --modified                  Use the modified timestamp field.
-M, --mounts                    Show mount details (Linux and Mac only)
-n, --numeric                   List numeric user and group IDs.
    --no-quotes                 Don’t quote file names with spaces.
    --no-symlinks               Do not show symbolic links
    --no-permissions            Suppress the permissions field.
    --no-filesize               Suppress the file size field.
    --no-user                   Suppress the user field.
    --no-time                   Suppress the time field.
    --no-git                    Don’t show Git status
-O, --flags                     List file flags on Mac and BSD systems and file attributes on Windows systems.
-o, --octal-permissions         List each file’s permissions in octal format.
-R, --recurse                   Recurse into directories.
-r, --reverse                   Reverse the sort order.
-s, --sort=SORT_FIELD           Which field to sort by.
-S, --blocksize                 List each file’s size of allocated file system blocks.
    --show-symlinks             Explicitly show symbolic links (when used with --only-files | --only-dirs)
    --smart-group               Only show group if it has a different name from owner
    --stdin                     When you wish to pipe directories to eza/read from stdin. Separate one per line or define custom separation char in EZA_STDIN_SEPARATOR env variable.
-T, --tree                      Recurse into directories as a tree.
-t, --time=WORD                 Which timestamp field to list. Valid timestamp fields are ‘modified’, ‘changed’, ‘accessed’, and ‘created’.
    --time-style=STYLE          How to format timestamps. Valid timestamp styles are ‘default’, ‘iso’, ‘long-iso’, ‘full-iso’, ‘relative’, or a custom style ‘+<FORMAT>’ (e.g., ‘+%Y-%m-%d %H:%M’ => ‘2023-09-30 13:00’).
    --total-size                Show recursive directory size (unix only).
-u, --accessed                  Use the accessed timestamp field.
-U, --created                   Use the created timestamp field.
-w, --width=COLS                Set screen width in columns.
-X, --dereference               Dereference symbolic links when displaying information.
-x, --across                    Sort the grid across, rather than downwards.
-Z, --context                   List each file’s security context.
